Self-Supervised Learning - Contrastive Learning

Self-Supervised Learning allows machines to learn from data without human labels. The system creates its own "pretext tasks" to understand the world. In this demo, we visualize SimCLR (Chen et al., 2020), a contrastive learning framework. The network learns by maximizing agreement between different views of the same image (Positive Pairs) and minimizing agreement between different images (Negative Pairs). By solving this task, it learns robust visual features, understanding that a "dog" is still a "dog" whether it's black and white, cropped, or blurry.
